# ✈️ Flight Delay Analysis & Prediction

## 📌 Overview
Analysis and prediction of flight delays using a dataset of 539,383 flights.
Built as part of my Data Science preparation for industry roles.

## 🎯 Problem Statement
Predict whether a flight will be delayed based on airline,
day of week, departure time, and flight length.

## 📊 Key Findings
- 44.5% of flights in the dataset are delayed
- Evening flights have higher delay rates than morning flights
- Delay rates vary significantly across airlines

## 🛠️ Tools & Technologies
- Python, Pandas, NumPy
- Plotly (interactive visualizations)
- Scikit-learn (Logistic Regression)
- Jupyter Notebook

## 📁 Files
- `flight_delay_analysis.ipynb` — Main analysis notebook
- `Airlines.csv` — Dataset

## 🚀 How to Run
1. Clone this repository
2. Install requirements: `pip install pandas numpy plotly scikit-learn`
3. Open `flight_delay_analysis.ipynb` in Jupyter
4. Run all cells
